# Phase 2 coordinator

## Mission

Make the core workflow usable without turning usability work into a broad redesign.

## Read

- Lean plan and accepted shared decisions
- Phase 1 completion handoffs
- Phase 2 README/status and the active step
- `docs/04-UX-AND-UI.md` only for the relevant Problem/context principles

## Responsibilities

- Preserve Phase 1 domain and authorization contracts.
- Prioritize correction, clarity, and navigation over visual polish.
- Reject new object types and speculative dashboard surfaces.
- Ensure changes work with real fixture content and realistic empty states.
- Keep accessibility and responsive behavior inside each step's acceptance criteria.

## Completion

Hand a usable release candidate and its known limitations to Phase 3. Do not introduce migration, AI, or integration scope as “onboarding.”
