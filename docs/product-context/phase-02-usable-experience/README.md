# Phase 2 — Usable Product Context experience

Status: Blocked by Phase 1

## Goal

Turn the functional chain into a coherent product that a person can understand, correct, and revisit without developer help.

## Steps

| Step                                                                      | State   | Result                                                       |
| ------------------------------------------------------------------------- | ------- | ------------------------------------------------------------ |
| [01 Context, activity, and search](./steps/01-context-activity-search.md) | Blocked | One complete navigable Problem page plus basic search        |
| [02 Correct and archive](./steps/02-correct-and-archive.md)               | Blocked | Users can fix mistakes, unlink, and archive safely           |
| [03 Usability and onboarding](./steps/03-usability-onboarding.md)         | Blocked | New users understand the workflow and its empty/error states |

## Exit criteria

- A Project admin can complete and later correct the full chain through the UI.
- A Project member can privately read and navigate the context.
- Problem context, provenance, rationale, alternatives, Outcome, activity, and history are understandable.
- Basic search reaches every canonical object.
- Empty, loading, error, permission, mobile, and keyboard flows are usable.
- No developer or seed script is required for the golden path.

At this point the product is an MVP release candidate. Phase 3 makes it safe to release and tests whether it is valuable.
