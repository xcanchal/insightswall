# Phase 3 Step 02 — Private MVP pilot

Status: Blocked by Phase 3 Step 01  
Owner: Human product owner with coordinator

## Outcome

The MVP is used for real product context and produces evidence for a Continue, Narrow, Revise, or Stop decision.

## Read

- Release-readiness handoff
- Lean-plan success condition
- Shared fixture and completed workflow

## Scope

- Load the canonical fixture for demonstration through supported interfaces.
- Create at least one real Problem/Decision chain for InsightsWall or another actual product.
- Invite no more than a few trusted product practitioners if useful.
- Observe whether users can complete the workflow, understand the page, and return to it during a later conversation.
- Record time/friction, useful moments, ignored fields, missing context, and reasons to revisit.
- Fix only critical blockers that prevent evaluation.
- Write the product decision and immediate next hypothesis.

## Useful evidence

- A Problem page is reopened during prioritization, implementation, or reconsideration.
- Decision rationale prevents repeated discussion or confusion.
- Evidence changes confidence in a Problem or Decision.
- Outcome recording changes what the team does next.
- Users voluntarily create a second chain.

## Do not add

Features requested before the core workflow is attempted, generalized analytics, automated ingestion, AI candidates, integrations, public launch, or a large beta program.

## Acceptance

- [ ] At least one real chain is attempted end to end.
- [ ] Critical usability failures and workarounds are recorded.
- [ ] Return/revisit behavior is observed or its absence is explicit.
- [ ] A written `Continue`, `Narrow`, `Revise`, or `Stop` decision exists.
- [ ] Any next phase is created only from that evidence.
