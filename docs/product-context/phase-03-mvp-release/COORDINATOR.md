# Phase 3 coordinator

## Mission

Protect data and privacy enough for a tiny real release, then prioritize evidence over feature accumulation.

## Read

- Lean plan and accepted limitations
- Phase 1 and 2 completion handoffs
- Phase 3 README/status and active step
- Current deployment, migration, auth, CI, and database configuration

## Responsibilities

- Define the exact release environment and pilot audience.
- Require evidence for migration, authorization, backup, and regression claims.
- Keep the release private and small.
- Separate critical blockers from preferences and polish.
- Record observed use rather than inventing success metrics from no traffic.
- End with an explicit product decision.

## Reject by default

Migration of legacy Suggestions, AI, integrations, feature flags, analytics platforms, notifications, billing, public launch, performance infrastructure, and broad post-pilot roadmaps.
