# Later, only after the product bet works

This is a parking lot, not an execution plan.

Reconsider these capabilities only after the Phase 3 private MVP pilot shows that at least one real Problem page is repeatedly useful:

- Import Suggestions as Evidence while preserving votes and comments.
- Source Artifacts and idempotent migration tooling.
- Candidate Problems/links with explicit human review.
- External integrations.
- Better search, ranking, or semantic retrieval.
- Workspaces, richer roles, and membership management.
- Notifications, comments, attachments, and background jobs.
- Public Product Context or roadmap cutover.
- MCP or agent-facing context APIs.

For each item, require a real observed trigger, an owner, and a new bounded plan. Do not expand this file into agent packets preemptively.
